## 🔴 Критические исправления (высокий приоритет)

- [ ] **Исправить поддержку тёмной темы** — Все компоненты (AdminPanel, Dashboard, SQLInjectionLab, TeacherPanel, AuthPages) используют захардкоженные светлые цвета без `dark:` вариантов
- [ ] **Реализовать отправку OTP email** — В `/api/auth/recovery/route.ts:33` TODO: OTP возвращается в ответе вместо отправки через nodemailer
- [ ] **Закрыть утечку данных пользователей** — Проверить все API endpoints на предмет возврата чувствительных данных (password_hash, tokens)
- [ ] **Добавить CSRF защиту** — Критично для платформы с аутентификацией и ролями
- [ ] **Настроить production rate limiting** — Текущий in-memory rate limiting теряется при рестарте сервера, нужен Redis

## 🟡 Безопасность и надёжность

- [ ] **Внедрить Content Security Policy** — Добавить HTTP заголовки CSP для защиты от XSS
- [ ] **Добавить HTTPS принудительно** — Редирект HTTP → HTTPS в production
- [ ] **Реализовать refresh token rotation** — Текущие JWT токены живут 7-30 дней без обновления
- [ ] **Добавить защиту от brute force** — Блокировка аккаунта после N неудачных попыток входа
- [ ] **Аудит безопасности API** — Проверить все endpoints на IDOR, mass assignment, injection
- [ ] **Валидация загружаемых CSV** — Импорт пользователей нуждается в строгой валидации
- [ ] **Шифрование чувствительных данных** — Phone numbers, OTP коды в БД должны быть зашифрованы
- [ ] **Security headers** — Добавить X-Content-Type-Options, X-Frame-Options, Referrer-Policy и др.
